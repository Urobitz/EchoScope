# EchoScope

**Steam Review Intelligence Engine — Work in Progress**

EchoScope is a Python application designed to gather, store and analyze steam reviews from a game to provide a sentiment overview and let the user quickly decide if the game is worth it or not.

The project's main goal is to simplify the identification of recurring complaints, praised features, and sentiment trends across thousands of reviews.

## Current Features

- Retrieve Steam reviews using a game App ID.
- Collect reviews through API pagination.
- Validate API responses.
- Store collected reviews in a SQLite database.
- Handle duplicate review records.

## Planned Features

- Sentiment analysis.
- Identification of recurring complaints and positive feedback.
- Review statistics and trend analysis.
- Game comparison tools.
- User-facing dashboard.

## Status

The project is currently in early development. The review collection and storage pipeline are implemented and work properly. I will be working on the NLP analysis and the user interface in the near future.
